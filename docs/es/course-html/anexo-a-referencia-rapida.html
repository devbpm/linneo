Módulo y paquetes

Linneo es una biblioteca para Java 21 o superior, sin dependencias en tiempo de ejecución. Con Maven:

<dependency>
    <groupId>io.github.devbpm</groupId>
    <artifactId>linneo</artifactId>
    <version>0.1.0</version>
</dependency>

El JAR es el módulo JPMS io.github.devbpm.linneo. Una aplicación modular añade requires io.github.devbpm.linneo; a su module-info.java. La declaración del módulo es esta:

module io.github.devbpm.linneo {
    exports io.github.devbpm.linneo;
    exports io.github.devbpm.linneo.annotation;
    exports io.github.devbpm.linneo.classify;
    exports io.github.devbpm.linneo.processing;
    exports io.github.devbpm.linneo.catalog.openmetadata;
    exports io.github.devbpm.linneo.catalog.datahub;
    exports io.github.devbpm.linneo.catalog.atlas;
    exports io.github.devbpm.linneo.ens;
    exports io.github.devbpm.linneo.export.odcs;
    exports io.github.devbpm.linneo.export.openapi;
    exports io.github.devbpm.linneo.export.postgresql;
    exports io.github.devbpm.linneo.extension.university;
    exports io.github.devbpm.linneo.extension.finance;
    exports io.github.devbpm.linneo.extension.supplychain;
    exports io.github.devbpm.linneo.extension.projectoperations;
    exports io.github.devbpm.linneo.extension.humanresources;

    uses io.github.devbpm.linneo.TaxonomyExtension;
}

La cláusula uses permite que Taxonomy.load() encuentre extensiones con ServiceLoader. No hay cláusula provides: las cinco extensiones incluidas se aplican de forma explícita.

Las seis anotaciones

Tabla A.2. Anotaciones, dónde van y sus elementos
AnotaciónSe aplica aElementos Para qué
@Categorycampo, componente de record String value(); opcionales Identifiability[] identifiability(), Confidentiality[] confidentiality(), Integrity[] integrity(), con {} por defectoLa categoría del campo; los opcionales elevan niveles o declaran la identificabilidad.
@DefaultCategoryclase String value(), String reason()Una categoría no personal para los campos sin anotación de la clase.
@CategoryByRowcampo, componente de recordString declaredBy(), String ceiling()Una categoría que cambia por fila, con su techo.
@DerivedFromcampo, componente de recordString[] value(); opcional Class<?> type()Un valor calculado a partir de otros campos, de esta clase o de type.
@Compositeclaseninguno Una clase de valor que se clasifica por sus campos, con rutas campo.parte.
@Exemptcampo, componente de record String value()Un campo técnico que no contiene datos del modelo, con su motivo.

Recuerda: en cuanto indicas un elemento opcional de @Category, tienes que escribir value =, y cada opcional admite como mucho un valor.

@Category(value = USER_CONTENT_PRIVATE, confidentiality = Confidentiality.HIGH)
private String counsellingNotes;

Problemas del clasificador

Cada Violation tiene type, path, severity, code y message. Todos los códigos son errores salvo DEPRECATED_CATEGORY, que es un aviso. Más detalle en el capítulo 6.

Tabla A.3. Los valores de Violation.Code y cómo se corrigen
CódigoCausaCorrección
UNCLASSIFIED_FIELDUn campo sin categoría propia ni valor por defecto aplicable, o que puede contener datos que el clasificador no ve.Añade @Category (o la anotación adecuada); en una clase sin datos personales, @DefaultCategory.
UNKNOWN_CATEGORYUna clave que la taxonomía no tiene.Usa las constantes de Categories o de tu extensión, y la misma taxonomía que la aplicación.
DEPRECATED_CATEGORY (aviso)Una clave obsoleta; el campo se clasifica con su sustituta.Cambia a la clave sustituta que indica el mensaje.
PERSONAL_DEFAULTUn @DefaultCategory con una categoría personal.Declara los campos personales uno a uno con @Category.
MISSING_REASONUn motivo o un declaredBy en blanco. Escribe un motivo que un revisor pueda comprobar.
CONFLICTING_ANNOTATIONSAnotaciones que se excluyen, o @Exempt en una relación o un compuesto.Deja una sola; clasifica la relación con @DerivedFrom o @Category, y el compuesto como un valor con @Category o @CategoryByRow.
LOWERED_LEVELUn nivel declarado inferior al de la categoría.Quita el elemento: en un campo los niveles solo suben.
AMBIGUOUS_VALUEUn elemento opcional con más de un valor.Indica uno solo.
IDENTIFIABILITY_NOT_APPLICABLEidentifiability en una categoría no personal.Quítala.
DUPLICATE_FIELDUn campo oculta otro de una superclase.Renombra uno de los dos.
UNKNOWN_SOURCEUna fuente de @DerivedFrom que no existe, está exenta o tiene un error, o ninguna fuente.Corrige la ruta o la fuente.
AMBIGUOUS_DERIVATIONFuentes con clasificaciones distintas en un derivado sin @Category.Declara la categoría del valor derivado.
WEAKER_THAN_SOURCEUn derivado que protege menos que una fuente. Declara una categoría al menos igual de protectora, o el valor anonimizado o agregado.
WEAKER_THAN_PARTSUn compuesto guardado como un valor protege menos que sus campos.Eleva la categoría del campo o del techo.
CYCLEUn compuesto que se contiene a sí mismo o derivados en ciclo. Rompe el ciclo o clasifica el campo como un valor.

Los exportadores y los catálogos devuelven texto o cuerpos JSON; ninguno se conecta a nada. Sus métodos para un campo aceptan un FieldClassification o un InventoryField (este último, con la taxonomía donde hace falta resolver su clave).

Códigos del comprobador de actividades

Cada ProcessingViolation tiene activity, severity, code, element y message. Un error es algo que haría la actividad ilícita tal como está declarada, o imposible de comprobar, y hace fallar verify; un aviso es un hueco del registro.

CódigoGravedadElemento Cuándo

MISSING_PURPOSEerrorPURPOSESSin finalidad.
MISSING_DATA_SUBJECTSerrorDATA_SUBJECTSSin interesados.
MISSING_PERSONAL_DATAerrorPERSONAL_DATASin datos personales.
ENTITY_NOT_CLASSIFIEDerrorPERSONAL_DATAUna entidad con errores de clasificación.

MISSING_SPECIAL_CATEGORY_CONDITIONerror SPECIAL_CATEGORY_CONDITIONCategorías especiales sin condición (9.2).

CONSENT_NOT_SUFFICIENTerror o aviso SPECIAL_CATEGORY_CONDITIONEn España, consentimiento explícito para datos del artículo 9.1 de la LOPDGDD: error si es la única condición, aviso si hay otras.

Element.isGovernance() es false para KEY, PURPOSES, DATA_SUBJECTS y PERSONAL_DATA (el alcance, que declara el código) y true para LEGAL_BASIS, LEGITIMATE_INTEREST, SPECIAL_CATEGORY_CONDITION, CRIMINAL_DATA_BASIS, LEGAL_REFERENCE, RETENTION e IMPACT_ASSESSMENT (la gobernanza, que mantiene el delegado de protección de datos).

Recetas

Cada receta es un fragmento que compila. Los nombres del modelo (Student, UniversityActivities) son los del ejemplo conductor del curso.

Verificar el modelo en un test

class ClassificationTest {

    @Test
    void theModelIsClassified() {
        new Classifier(Taxonomy.load()).verify(ModelClasses.inPackageTree(Student.class));
    }
}

Decidir qué se escribe en un log

Map<String, DisclosurePolicy.Treatment> treatments =
        DisclosurePolicy.forLogs().treatments(classifier.classify(Student.class));
treatments.get("email");              // MASK
treatments.get("disabilityDegree");   // OMIT
treatments.get("createdAt");          // CLEAR

Comparar el inventario guardado con el modelo

DataInventory stored = DataInventory.fromTsv(Files.readString(Path.of("inventory.tsv")));
DataInventory current = classifier.inventory(List.of(Student.class, Enrollment.class),
        type -> type == Student.class ? "students" : "enrollments");
InventoryDiff diff = InventoryDiff.between(stored, current, taxonomy);
diff.weakening().forEach(System.out::println);

Aplicar una extensión incluida

Taxonomy university = Taxonomy.builder()
        .withStandard()
        .extend(new UniversityTaxonomy())
        .build();

Graduar el cambio de la taxonomía

Taxonomy released = Taxonomy.fromTsv(Files.readString(Path.of("released-taxonomy.tsv")));
TaxonomyDiff diff = TaxonomyDiff.between(released, Taxonomy.load());
System.out.println(diff.requiredBump());
diff.requireCompatible();   // TaxonomyException con cada cambio incompatible

Verificar las actividades y escribir el registro

ProcessingRecord record = new ProcessingChecker(Taxonomy.load(), Jurisdiction.SPAIN)
        .verify(UniversityActivities.all());
Files.writeString(Path.of("target/record-of-processing.md"), record.toMarkdown("Example University"));
Files.writeString(Path.of("target/record-of-processing.json"), record.toJson());

Fallar la compilación solo por el alcance

List<ProcessingViolation> scopeErrors = checker.checkAll(UniversityActivities.all()).stream()
        .flatMap(checked -> checked.errors().stream())
        .filter(violation -> !violation.element().isGovernance())
        .toList();
assertTrue(scopeErrors.isEmpty(), () -> "Fix the scope of the activities: " + scopeErrors);

Cribar la evaluación de impacto

for (CheckedActivity checked : checker.checkAll(UniversityActivities.all())) {
    System.out.println(checked.activity().key() + ": " + checked.screening().summary());
}

Orientar una brecha

BreachAssessment breach = BreachAssessment.builder()
        .affected(classifier.classify(Student.class).fields())
        .confidentiality(BreachAssessment.Exposure.KNOWN_RECIPIENTS)
        .individuals(37)
        .build();
System.out.println(breach.explanation());

Empezar la respuesta a un interesado

SubjectRights rights = SubjectRights.of(record, taxonomy, DataSubjects.STUDENT, Jurisdiction.SPAIN);
for (SubjectRights.ActivityRights activity : rights.activities()) {
    System.out.println(activity.activity().activity().key() + ": "
            + activity.entitlement(SubjectRights.Right.ERASURE).availability());
}

Categorizar un sistema según el ENS

EnsCategorization ens = EnsCategorization.builder()
        .information(classifier.classify(Student.class))
        .declare(EnsCategorization.Dimension.AVAILABILITY, EnsCategorization.Level.MEDIUM, "fixed deadlines")
        .declare(EnsCategorization.Dimension.AUTHENTICITY, EnsCategorization.Level.MEDIUM, "students sign in")
        .declare(EnsCategorization.Dimension.TRACEABILITY, EnsCategorization.Level.MEDIUM, "changes are audited")
        .build();
System.out.println(ens.summary());

Exportar a herramientas y catálogos

ClassClassification student = classifier.classify(Student.class);
List<String> labels = PostgresAnonymizer.of(DisclosurePolicy.forLogs())
        .labels(student, path -> "students." + path.toLowerCase());
String openApi = OpenApiExtension.toJson(student);
List<String> tags = OpenMetadataCatalog.of(taxonomy).tagsOf(student.field("email").orElseThrow());
List<String> terms = DataHubCatalog.of(taxonomy).termsOf(student.field("email").orElseThrow());

Para el campo email de Student, tags es [DataCategory.user.contact.email, PersonalData.Personal, PII.NonSensitive, Confidentiality.Low, Integrity.Medium, Identifiability.Identified].
